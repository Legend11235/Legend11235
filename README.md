# Hi, I'm Sohum Guha

4th year Honours CS student at McGill. I work across compilers and machine learning: I build ML models end to end, and I'm digging into the systems side of what makes them run fast. Also a huge Man City fan. ⚽️

## What I'm working on

- **tensor_compiler** (C++, MLIR): a compiler for a small tensor expression language. Hand-written lexer and recursive descent parser, a custom MLIR dialect defined with ODS/TableGen, and MLIR generation from the AST. Currently working on lowering through linalg and running the result end to end, checked against my own C++ tensor engine.
- **Eclipse OMR** (C++): contributing to the runtime under OpenJ9, including AArch64 codegen work on switch-statement lowering.
- **COMP 400 research** (starting Winter 2027): compiler optimization research
- **Machine learning:** refactoring my FPL model into a clean scikit-learn/XGBoost pipeline, and comparing sequence models to boosted trees on time-series player data.

## Selected projects

### Compilers and systems
- **[tensor_compiler](https://github.com/Legend11235/tensor_compiler)**: see above.
- **Mini-C compiler** (Java): COMP 520 course project with a Chaitin-style graph-colouring register allocator (CFG, liveness analysis, interference graphs, spilling), plus OOP support with vtable dispatch.

### Machine learning
- **[Transformer from Scratch](https://github.com/Legend11235/transformer-from-scratch)** (PyTorch): attention and training loops implemented by hand.
- **[FPL Optimizer](https://github.com/Legend11235/your-fpl-repo)**: full-stack ML app that predicts Fantasy Premier League points and builds optimal squads.
- **[Equity Portfolio Optimizer](https://github.com/Legend11235/equity-portfolio-optimizer)**: trains signals from market data and 10-K text, then optimizes long/short weights with risk caps, turnover limits, and performance tracking.
- **Neuroscience data pipeline**: automated extraction and visualization for behavioral + eye-tracking data.
